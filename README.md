# Noise prediction for propeller design
OpenVSP propeller Geoms are evaluated with VLM aerodynamic analysis (VSPAero). 
Secondly the analysis results can be used as input for Hanson based Tonal loading noise prediction method.
The tool is in its early stages and serves as a part of my Msc. Thesis at TU Delft with the goal of designing
low noise propellers.
